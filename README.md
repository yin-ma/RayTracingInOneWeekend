# Ray Tracing in One Weekend Series

This repository contains my personal study and implementation of the "Ray Tracing in One Weekend" series of books by Peter Shirley. It includes the code for all three books in the series.

## About the Series

The "Ray Tracing in One Weekend" series is a collection of books that teach you how to write a ray tracer from scratch. The books are:

1.  **Ray Tracing in One Weekend**
2.  **Ray Tracing: The Next Week**
3.  **Ray Tracing: The Rest of Your Life**

You can find the official website for the book series [here](https://raytracing.github.io/).

## Repository Structure

The repository is organized into three main directories, one for each book:

*   `src/InOneWeekend`: Contains the code for the first book.
*   `src/TheNextWeek`: Contains the code for the second book.
*   `src/TheRestOfYourLife`: Contains the code for the third book.

Each directory is a self-contained C++ project that can be built and run independently.
